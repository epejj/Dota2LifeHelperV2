## Capabilities

| Module | Description |
| :--- | :--- |
| **Auto-Accept** | Accepts queues while you're AFK. |
| **Team ACE / DEC** | Automatically accepts or declines queues for your party. |
| **Auto-Pick / Lane** | Tired of someone beating you to the pick? No Herald will ever beat this module. Secures your lane perfectly. |
| **Auto-Ban** | Insta-bans your selected hero. Optimized for Turbo mode. |
| **Auto-Skill** | Automatically levels up your selected skills in-game as you level up. |

## Setup

1. Download the latest binary from [Releases](https://github.com/epejj/Dota2LifeHelperV2/releases).
2. Run the executable.
3. Assign your binds via the UI.
